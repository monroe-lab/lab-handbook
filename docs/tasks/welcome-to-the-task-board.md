This board tracks lab to-dos. Cards are regular markdown objects in `docs/tasks/`, so you can open one (click it), add notes, wikilinks like [[grey-monroe]], and assign people or a project in the fields.

- Drag a card between columns to change its status
- Type in the box at the top of a column and press Enter to add a task
- Click a card to open and edit it (add people, project, due date, notes)
